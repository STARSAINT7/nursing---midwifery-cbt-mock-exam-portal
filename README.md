# Nursing & Midwifery CBT Exam Portal

A single-file HTML5 Computer-Based Testing application designed for Nursing and Midwifery Council exam prep[cite: 4].

## Features
* **Dynamic Mock Exams:** 50 randomized questions with a 30-minute timer[cite: 4].
* **Core Specialties:** Covers Med-Surg, Maternal & Child, Psych, and Community Health Nursing[cite: 4].
* **Admin Dashboard:** Manage questions, view candidate scores, and export results to CSV[cite: 4].
* **Interactive UI:** Question palette, real-time timer, instant grading, and answer reviews[cite: 4].
* **Zero Dependencies:** Pure HTML5, CSS3, and Vanilla JavaScript—runs entirely offline in any browser[cite: 4].

## Quick Start
1. Download `index.html`[cite: 4].
2. Double-click to open in any web browser.
